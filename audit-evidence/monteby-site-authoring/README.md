# Rejected Monteby site-authoring prototypes

These files are preserved only as audit evidence. They are deliberately outside
`monteby-site-authoring/`, outside the npm `files` allowlist, and outside every
installed skill.

Do not execute, document, or restore them as an authoring route. They were
rejected because they contain one or more of:

- credential-bearing command examples;
- manual browser snippets or hand-authored node maps;
- blind conflict retries;
- partial-depth or tolerance-based completion rules;
- residual CSS as a normal completion mechanism;
- silent evidence loss or an unverified parallel pipeline.

The normative implementation is the versioned state machine in
`monteby-site-authoring/references/mechanical-workflow-protocol.md`.

The completed audit and verification record is
`audit-evidence/monteby-site-authoring/AUDIT-2026-07-26.md`.
